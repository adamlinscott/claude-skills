#
# Two deliberate exceptions, so this file does not overstate its own rule:
#
#   • A guided setup ("Set it up for me") shows no checklists at all, so a beta feature marked

#     says, unless --beta is passed. Nothing still in development turns itself on with nobody
#     watching.
#

#
#   skill        <name from skills.txt>
#   instruction  <file name in ./instructions, without the .md>
#
# Move something out of beta by deleting its line — a skill then installs by default, and an
# instruction moves to the installer's "Other features" question. Blank lines and lines
# starting with # are ignored. The installer reads this at run time; it never needs editing.
