# How the installer lists the skills.
#
# One line per checkbox:
#
#   <name> | <folders> | <what it does>
#
#   name         what the installer shows, and what beta-features.txt refers to.
#   folders      comma-separated folder names under ./skills that this entry installs.
#                Several folders can share one checkbox — an alias like /seatbelts or
#                /to-the-point is another way to invoke the same skill, not another choice.
#   description  written for the PERSON INSTALLING, not for Claude. The description inside a
#                SKILL.md is written to help Claude decide when to use the skill; it is long and
#                technical and makes a poor answer to "what is this?". Write a plain sentence or
#                two here instead.
#
# A folder with no line here still installs, on its own, with no description. Blank lines and
# lines starting with # are ignored. The installer reads this at run time.

assumption-inventory | assumption-inventory | Before a long job, checks what the plan takes for granted — which files exist, what may be changed, what "finished" means — and asks you about anything it had to guess.

context-audit | context-audit | Reviews the instructions and notes Claude reads in a project, and reports what is bloated, broken, or contradicting itself. Only reports; changes nothing.

debrief | debrief | Reads back through your past Claude sessions to find the corrections you keep repeating, asks you why, and can write the answers up as project rules.

fresh-eyes | fresh-eyes | Gets a second Claude to read your finished work with no memory of the conversation, then compares that reading against what you actually asked for. Catches what was missed.

goal-workflow | goal-workflow | Hands Claude a settled plan and lets it build the whole thing on its own, checking its own work as it goes. Long-running, and it will use a lot of tokens.

memory-audit | memory-audit | Tells you what Claude remembers about a project and whether any of it has gone stale. Only reports; changes nothing.

reground | reground | Stops Claude when it has wandered off the task or started inventing files and APIs, and pins it back to what is really in your code.

seatbelt | seatbelt, seatbelts | Decides up front what Claude may do in a project without asking, and what it must never do. Set it once, then let Claude run without watching every step.

ttp | ttp, to-the-point | Makes Claude's replies short and direct — the answer first, the detail only if you ask for it. Big decisions still come back to you.
