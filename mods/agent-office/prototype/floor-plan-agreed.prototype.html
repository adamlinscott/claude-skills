Agent Office floor plan

The design agreed on 10 October, drawn from the same busy afternoon in claude-skills: eight sessions, about 25 subagents. Each room is one piece of work, named after what it is doing. Click anyone to see what they are doing.

Key

The rules this drawing follows

  • Rooms are pieces of work. In v1 each session is its own room. A room can already hold several sessions (stacked tables), so related work and other people can join one room later, with work groups inside it.
  • No job zones. Everyone in a room sits at one table with their lead. The hat or prop shows the job.
  • Room name is the job. The session's title in large type, the branch and checkout in small print.
  • Status colour on the figure: amber working, green done, faded idle, purple stalled (!) or failed (×).
  • Write bubble: amber while an agent writes a file. Red when any other agent, in any room, edited that file in the last 30 minutes. Later, a red bubble triggers a git check and conflict help.
  • Lines only while an answer is owed. Dots travel from the agent waiting toward the agent working. The line goes away when the answer arrives. v2 messaging adds lines between any two agents.
  • Info icon over a reviewer that finished with findings. No board.
  • Layout is a separate step. A ships first; D replaces it without changing how a room is drawn.
